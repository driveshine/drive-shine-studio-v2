# Drive Shine Studio

Drive Shine™ — premium marketing website for an independent automotive Pre-Delivery Inspection (PDI) and car care products brand based in Hyderabad, India.

## Stack

- Vite + React 18 + TypeScript
- Tailwind CSS v4
- React Router DOM v6
- GSAP + ScrollTrigger — scroll reveals, counters, parallax
- Lenis — smooth inertial scrolling
- Framer Motion — page transitions, micro-interactions
- Embla Carousel — product and testimonial sliders
- lucide-react for icons

## Development

Requires Node.js 18+.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

## Logo

Place the Drive Shine logo at `src/assets/logo.png` and `public/favicon.png`.  
Both are currently using the same placeholder image.
